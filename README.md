# cnation Youtube Downloader

유튜브 링크를 입력하면 원하는 해상도로 영상을 저장할 수 있는 모바일 친화적 웹앱입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 배포

Vercel에 이 저장소를 연결하면 자동으로 빌드/배포됩니다 (Next.js 프로젝트, 별도 환경 변수 불필요).

## 기능

- 유튜브 링크 입력 → 해상도별 mp4 다운로드
- 음악 파일(mp3) 다운로드 (ffmpeg로 오디오 트랙을 mp3로 변환)

## 참고 사항

- 본인이 저작권을 보유했거나 다운로드가 허용된 영상만 저장해 주세요.
- 유튜브 정책 변경으로 인해 영상 정보 조회나 다운로드가 일시적으로 실패할 수 있습니다.
- 현재는 오디오와 영상이 합쳐진(mp4, progressive) 포맷만 지원하며, 이 경우 최대 해상도는 영상마다 다를 수 있습니다(보통 720p 이하).
- mp3 변환은 서버에서 ffmpeg로 처리되며, 영상 길이에 따라 시간이 걸릴 수 있습니다.
